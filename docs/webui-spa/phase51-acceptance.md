# Phase 5.1 部署验收清单（0.6.1，LuCI 风格重组）

> 部署方式不变：用户手动 `docker compose pull && docker compose up -d`。
> 本文按顺序走一遍即可完成验收；任何一步不符合预期 → 走文末回滚。

## 1. 部署

```bash
docker compose pull && docker compose up -d
docker compose logs --tail=20   # 确认 webui 无报错启动
```

## 2. 版本确认

打开 `http://<NAS_IP>:8081/api/version`，确认：

- `webui.version` = **0.6.1**
- `ui_mode` = `spa`

面板顶部（顶栏右侧）不再显示 MCP 与版本两项（已精简），版本信息在总览页底部版本卡。

## 3. 菜单树（3 组 11 页）

左侧导航自上而下：

- **总览**（单页）
- **系统运维**（组）：数据同步 / 私有存储 / 系统健康 / 诊断中心 / 日志中心 / 通知中心（红点徽标）/ MCP 观测
- **模拟盘**（组）：模拟盘 / 审计报告 / 信号体检

每页点一遍，确认无白屏、无 404。

## 4. 新功能验收

| 功能 | 位置 | 验收标准 |
|---|---|---|
| 一键诊断 | 系统运维 → 诊断中心 | 点「立即体检」：六项检查逐项显示 通过/异常（上游 GitHub 与妙想 API 在网络受限时显示降级提示属正常） |
| 日志中心 | 系统运维 → 日志中心 | 三区（同步日志/容器日志/模拟盘事件）有内容；搜索框输入关键字能过滤 |
| 同步趋势图 | 系统运维 → 数据同步 | 页顶趋势图有数据点或「暂无趋势数据」空态 |
| 环境信息卡 | 系统运维 → 系统健康 | 显示 python/架构/镜像 tag/启动时间/数据最新日 |
| 总览驾驶舱 | 总览 | KPI 五行 + 今日进度 + 情绪投递徽标 + 告警 top3 + 版本卡 + /legacy 入口 |

## 5. 旧路径重定向

访问以下旧地址应自动跳到新页面（不 404）：

`/data/sync` → 数据同步；`/data/mydb` → 私有存储；`/ops/system` → 系统健康；
`/ops/version` → 总览；`/data` → 数据同步；`/alerts` → 通知中心

## 6. 逃生通道复核

- `http://<NAS_IP>:8081/legacy` = 旧面板原样可用。

## 7. 回滚

**面板级回滚（推荐，零停机）**：compose 里给容器加环境变量 `WEBUI_UI=legacy`，
`up -d` 后根路径整体回到旧面板；移除变量即回新面板。

**镜像级回滚**：`docker compose` 把镜像 tag 改回上一个已知良好的
`ghcr.io/awoeyiwuyua/stockdb-ai:latest@<旧 digest>` 或重打上一个版本 tag。
